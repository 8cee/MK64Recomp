# MK64Recomp Android

Android-focused Mario Kart 64 recompilation project with mobile controls, diagnostics, and online multiplayer support.

## Goals

- ARM64 Android APK
- User-supplied ROM/assets only
- Touch and physical controller support
- Diagnostic/crash reporting
- Local and online multiplayer
- Save management
- GitHub Actions Android builds

## Legal

This repository does not include Nintendo ROMs or proprietary game assets. Users must provide their own legally obtained ROM.
